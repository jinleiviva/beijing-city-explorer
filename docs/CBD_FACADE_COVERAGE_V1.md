# CBD 外立面覆盖第一批

2026-10-17。所有计数以源 OSM ID 去重，地理足迹和楼高保持原样；门窗尺寸、部分朝向和构件细位为近似。参考照片不作为纹理，不包含在站点/源码包。

## 数量与边界

- 独立 CBD 数据 200 个足迹。
- 100 栋普通背景建筑增加 2–3 组浅窗框/窗台或边框，按玻璃/石材/住宅/低裙楼四类匹配既有 shader 的窗格相位；不把这些算成真实招牌，也不称每面已精修。
- 8 栋主建筑增加首层门框、玻璃/柱网或檐底构件：国贸 A/B、中国尊、央视、国贸北商城、嘉里酒店、汉威、电视文化中心。
- 4 栋新有图证楼名：汉威、东亚银行、中国大饭店、FFC。共 8 处实体字，保持可读的实际繁简文字。徽记图形未清楚核实，没有猜制。
- 上述集合去重 111/200，即55.5%足迹含本批某种细部。此比例不是招牌覆盖率，也不是写实复刻或像素可见率。
- 加此前嘉里酒店，累计有图证楼名 5 栋；商城原创中性店招/海报另计一个建筑，大幅原创广告 2 处也都在这一个商城，不能虚增楼数。

## 有据楼名

1. 汉威：照片为“漢威大廈 / HANWEI PLAZA”，中央外石门框及较低内层横带的金字；参考 https://www.hanweidasha.cn/ 。这是房产信息站外观，不称业主官方。绑定既有中央入口，南向为现模型推断。新增深框、玻璃细分与文字均保留现有100m/93m塔高，不上移为屋顶牌。
2. BEA：红色“BEA / 東亞銀行”，上部封闭幕墙带。MFG照片 https://www.mfgchn.com/office/beijing/bpc/ 及 SOM 外观 https://www.som.com/projects/china-world-trade-center-3a/ 。两相邻面映射为东长面/南短面属场地推断，不是精确测绘，不给四面重复挂同牌。
3. 中国大饭店：官方 https://www.shangri-la.com/cn/beijing/chinaworld/about/map-directions/ 的到达图支持南立面顶部檐带双语字及入口雨棚字。源泛化体块实际高度37.847m不变，照片曲面玻璃仅在原平面墙上作玻璃/细金属格近似，不能称完整复刻；不借用照片东邻独立办公塔的 China World 标。
4. FFC：业主 https://www.hki.com.cn/company-business/commercial-operations.html 照片支持两相邻顶部立面“FFC”。265m源高不变，具体面向为推断，曲冠形状本批未重建；未凭不清红方标猜内部图形。

## 材质与性能控制

标准：100栋窗框17,088三角/4批，8栋主楼3,912三角/6批，4栋楼名及附着立面10,892三角/10批。轻量分别10,056/3,204/10,580三角；每档20个新增材质批次，均不增加阴影提交或点光源。字为真实带厚度三角网格，Noto Sans CJK SC Bold字形，完整SIL OFL与Adobe版权随模块。

标准、轻量的所有新对象都实际生成。4个专用观察点两块字框均15/15网格射线在画面内无遮挡，投影字高约10–29px；该数据只证明构图和遮挡，不能代替实际图。整体天际线的这些字仅约1px高，不可称远景可读。

## 画面与验收

汉威 v1 与 BEA/酒店/FFC 修后 v2 的 800×500 CPU 图已实际检查。BEA/FFC 旧悬空字已贴合真实宿主，酒店雨棚下有实际内退门洞。酒店大实墙、汉威底部暗缝与 FFC 远机位像素较小仍是限制，不能称整栋外立面完整复刻。旧失败图保留。原WebGL浏览器仍未取得可见画面，材质环境反射、控件交互、低配帧率不能宣布通过。用户需要的逐楼标识仍在扩展，不能把111栋浅细节说成111栋实景招牌。
