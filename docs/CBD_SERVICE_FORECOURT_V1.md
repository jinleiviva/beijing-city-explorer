# CBD 街边设施与前场行人 · 候选10

2026-10-17。当前主线仍为独立 CBD；本批不扩大到其他街区。

## 新增实体

- 一个黑色窄停车导视柱，白色 P 与向前箭头；一个灰色百叶市政柜，包含真实外壳、百叶与落地支脚。
- 两件小型信号附属设备接到现有东向信号横杆上：摄像机外壳与控制箱。不新增灯杆林，不改变信号周期。
- 标准552、轻量504三角，均4材质批次，约40KB几何缓冲；没有照片纹理、图片下载或额外点光源；街具新增材质批不专设假阴影。
- 设施造型来自北京 CBD 西北区设计方街拍。具体放置点/尺寸是道路约束下的作者安排；P箭头只是停车导视类型展示，不代表实测停车入口，不能用作导航。

## 前场行人

原52人总池、8名商城固定行人不增。将其中2名分配到现有光华路路缘铺地的15.001m展示路径上，实际行走区间为内侧11.001m。未移动树、未另铺地、未改变源OSM路网。追加第三路径改变了全部8人的取模分配/初始相位，因此检查了全部8人的连续运动。

实际地面采样330点最大高差小于5mm，地面为0.58m；鞋底几何正好接此地面。独立静态扫掠7712点都位于原有裁剪铺地内。以保守0.55m身体包络计，最小道路净距0.2872m；实际活动区间到已知灯座等设施至少0.5528m。

120秒整场运行：固定8人建筑穿入0，新增2人入车道0、P牌/市政箱碰撞0；最小固定人身体净距0.3659m，新增两人净距0.3759m，最大单步0.03167m，全部转身均持续模拟。其余近邻通用行人与新增2人无碰撞。新增2人在8秒镜头下约84/81px高（800×500投影估算，不能代替实际可见像素）。

保留原店招路灯观察点；新增“光华路·行人与街边设施”近景，相机在原有铺地上，相对铺地眼高1.82m。没有移走原树或放大设施。

## 已有像素与验收边界

原 shops 机位800×500真几何CPU图已核：P及箭头清楚，市政箱百叶、支脚与落地可见。signalDetail图能辨横杆设备外壳，但尺寸小，不称镜头/连接件精细可读。前场两人新版图实际可见约80px人形，P与箱体更大；原树干仍遮书店部分字。不可变快照四只鞋底与实际铺地误差仅1.12e-8m，接地成立，但原腿/鞋不投影导致弱接触影。随后只补腿/鞋两个实例阴影批次，总4批，不改曝光/灯光/几何；修后同机位图已看到腿/脚连接的阴影。严格快照审计证明只这两个castShadow标志改变，原几何/材质/相机/灯光和车流矩阵均逐项一致；不把CPU近似影子当WebGL阴影品质验收。

CPU桥接保真实Three几何、LOD、面朝向和逐时刻车流；玻璃反射、程序shader与光照为近似。当前私有站原WebGL实画、控件交互、设备FPS仍未验。
