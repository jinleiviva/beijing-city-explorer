启动新版（Python 3，已支持WebGL2的浏览器；无npm安装、无资源下载）
1. 将本增量ZIP解压到一个新的独立目录，保留原版文件不变。
2. 准备原已交付 beijing-city-runtime.zip，不需要解压它。
3. 在本增量目录执行：
   python3 scripts/serve_round2.py --baseline-zip "/完整路径/beijing-city-runtime.zip" --port 8772
4. 在同一台机器的正常浏览器打开：
   http://127.0.0.1:8772/
   轻量入口：http://127.0.0.1:8772/project/web/index.html?quality=low&r2review=1
   标准入口：http://127.0.0.1:8772/project/web/index.html?quality=standard&r2review=1
5. 结束后在服务器终端按Ctrl+C。服务仅绑定127.0.0.1，不上传、不公开发布。
也可提供已有原项目目录：python3 scripts/serve_round2.py --baseline "/完整路径/beijing_city_8h"
如果Python不存在，先报告，不需要为本包擅自安装系统工具或修改安全设置。
禁止使用file://直接打开模块页面或修改浏览器安全参数来代替正常HTTP预览。

新版实图验收入口
右下角有“样板正面”“侧向检查”“冻结画面”“继续人车”“保存场景图”“保存验收记录”。
先等场景加载完成、错误为0，再等待周边细节加载稳定。标准和轻量各查看一次正面/侧面。
请实际确认门窗深度、台阶接地、灰瓦木石区分、招牌位置、树冠透空和颜色是否自然；有问题就继续修同一小样。
测试鼠标拖动旋转、滚轮缩放、触摸旋转/缩放（设备支持时）、人物与车的连续移动。不要只看静止截图就判定交互通过。
“r2review=1”入口固定交通初始模拟时间24秒，便于复核；点击“继续人车”恢复动态。它仍是实时WebGL场景。
“保存场景图”直接保存当前渲染画布；验收记录包含源码版本、画质、相机、WebGL错误、资源/人车统计及性能样本。
未建立同机同档性能对照前，不声称帧率提高或满足性能增量预算。软件渲染与浏览器设备差异会影响数值。
