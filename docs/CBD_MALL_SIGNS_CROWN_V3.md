# 北商城可见冠层与中文店招 V3

2026-10-17。此批只深化已选北商城转角，已对两张真实几何 CPU 图复核：冠层体积有效，店招仍需安装与对比修正；原 WebGL 验收仍未完成。

## 新增内容

- 已精修的 8 棵商城近树改为每棵 5 组重叠但不规则的主叶团，辅以中、小叶团和原有分叉树干。树位、总高、原冠幅与根部接地不变；另 12 棵精修树和全区 1,250 树位不改。标准档 16,000、轻量档 7,840 叶冠三角面，均为真实闭合三维几何。
- 3 块柱间固定招牌：街角咖啡、读书空间、城市影像。
- 2 幅原创展示海报：一页一城·慢读时光、城市影像·光影之间。书页、城市轮廓为原创矢量几何。
- 2 块固定在原柱体上的入口导视。所有文字牌注明“风貌示意”；店名与展览不是已核实真实商户。
- 每档仅 5 个既有材质批次，非发光、无新纹理。标准 6,795 / 轻量 5,816 三角面；3 个发布资产合计 74,637 字节。轻量保留所有主标题、海报主图和示意说明，只减装饰细线和次标题。

## 安装与可读性检查

招牌厚度 0.14 m，横支架搭接原柱，双支座连招牌；海报有相连落地腿与脚，底部为原地表 -0.02 m。海报与玻璃留 0.15 m，最小水平门口净距 1.286 m。没有改变门、原足迹或上部体量。

冻结源有总览与首层两种用途：总览保持上一版位置、目标、视角与 8 秒时刻完全不变；“店招与首层”预设放在实际商城前场，视高 2.35 m，距车道路缘 15.61 m。近景三块标题中心射线均无实体遮挡，预估字高 9–15 px；总览字仅约 2 px，不能称远景文字可读。射线与像素预算不是实际图验收。

两档单件字形遮挡、支架接触、门口净距、材料与几何预算测试通过。120 秒真实全场模拟未见车身穿楼、出车道或可见瞬移，最小同边间距 1.8016 m，连续车流未中断；该结果不代表浏览器帧率。

## 验收范围

本批同机位总览显示 8 棵冠层不再干枯稀疏，仍有低多边形棱面。首层图中中文与海报真实出现，但原柱从斜向遮挡字边，阴影下对比偏低。不能以标题中心射线通过代替整字验收。已要求将牌安装到柱外缘净面、保留实体托架，并用局部低亮灯箱面和深色字；当前 V3 没有发布。CPU 桥接保留源几何、实际 LOD、面朝向、车流矩阵和相机；材质程序、玻璃环境与光照仍是近似。原 WebGL 编译、交互、触摸、设备帧率未通过，不用 CPU 开发机耗时替代。
