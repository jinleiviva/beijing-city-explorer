# 北京 CBD 独立街景候选 10

2026-10-17。当前只打磨 CBD。烟袋与北海不推广。已通过真实几何 CPU 图的阶段检查；整体精致度仍未达标，原 WebGL 着色、浏览器操作与设备性能未验。

## 打开

私有站默认以暖灰蓝灰配色进入国贸北商城西北角 40 m 虚拟局部总览并播放车流。入口 /project/web/cbd-preview.html。另有 CBD 街块、光华路近景、北商城店招与首层、店招路灯近景、中国尊街面、中国尊楼顶和嘉里酒店顶部标识观察点。支持旋转、缩放、标准/轻量、暂停、两种日光、保存画面/运行记录；本批环境没有实际操作浏览器控件，不能称交互通过。普通静态 HTTP 服务即可运行，无依赖安装或特殊安全配置。

## 边界与未达项

道路尺寸、信号周期/灯杆位置、设施细位与树种均是推断，非交通工程或逐物测绘。CPU 桥接保 Three LOD、面朝向、矩阵及实际车流时刻，但程序 shader、玻璃环境和光照近似。本批近景单帧 21.43 秒、约 856 MiB 峰值仅为开发机离屏测量，不是浏览器 FPS。

当前新冠层体积有效但仍显低多边形；残余球冠、大片广场和上部空墙仍需细化。左缘第三块牌不在本近景下完整清楚验收。没有原 WebGL 实画、shader 编译、旋转缩放实测及低配 FPS，不宣布美术整体达标。冻结首轮 ZIP 未动，50 条街景目标未达到，此版本不增加已验收街道数。
