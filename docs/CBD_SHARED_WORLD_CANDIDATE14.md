# 北京整体与 CBD 共用场景：候选14

北京全景和 CBD 细览现在调用同一个 CBD 装配器，共用真实坐标、建筑体量、幕墙入口、楼名与广告、街具、树木和车人造型。全景保留自己的相机、灯光和城市场景底板。候选12屋顶修正与候选13局部道路单面归属均保留。

## 去重与边界

- 全景中原有的4地标、56个细化建筑、4场地、136个背景楼、335个地面要素和37个土地利用要素，由精修 CBD 相应对象接替，不再叠一套。
- 以完整原路网计算高程，再分配城市/CBD所有权。76,158端点检查通过，774过街方向无重复；6个边界信号组的11个外部进路由CBD唯一控制。
- 这是两组互斥展示交通池，不包含跨街区长旅程的无缝交接功能。

## 实际检查

独立CBD和宿主CBD分别运行120秒，采用顺序单进程，623个网格的几何/实例/材质哈希完全一致。4、30、60、120秒时88辆车和52名行人的完整记录相同；1253棵树相同，4次标准/低配切换通过。

真实周边局部宿主的总览与边界各有一张800×500 CPU离屏图。它们使用原相机和原光照，没有用独立CBD场景冒充全城装配。图中可见共享街区与实际周边道路、楼体及植被；远处仍是简化城市代理。此项不是完整北京所有区域的画面验收。

## 历史缓存修正的边界

CBD周围16个近景缓存tile有35,750个三角形的索引绕序与原法线相反。本批只交换这些严格反向三角形的两个索引，位置、法线、颜色、UV、材质、数量、边界与所有权不变。逆操作可逐字节还原。

旧边界截图中的5个tile，15,743个三角形内的9,693个反向面现为0；同机位新图中原大块黑墙恢复合理灰蓝/暖灰受光。远景BoxGeometry及其正行列式实例没有该问题，没有翻面。其余205个近景tile仍有422,386个历史反向三角形，未在本批修正。

## 仍待验证

云浏览器WebGL被禁用，因此没有全城实时启动、缩放、GPU内存或FPS验收。CPU桥接近似了材质与光照，不等于WebGL实际渲染。

用户反馈商城前与后方广场缩小时仍闪烁，关闭阴影也仍出现。此问题不由共享整合解决；已另定位国贸土地面与大CBD土地面同高重叠，以及仅8mm层距的石板，下一独立候选处理。不要把候选14理解为地面闪烁已经全消。
