# 北京 CBD 街景精修 · 本轮交付摘要

2026-10-17，候选10。独立CBD局部工程，保原全城入口；并未完成全北京50条街景目标。

## 主要成果

1. 国贸北商城首层柱网、退入玻璃、入口、真实厚度店招及海报；三组原创示意商铺名、两幅小海报、两幅大商业广告。窗格与挂装是实体几何，中文字体许可随源。
2. 中国尊有图证的顶部平台/H/环线和尊口细节；嘉里、中国大饭店、汉威、东亚银行、FFC、三星、世界华商中心、正大、千禧、中国人寿金融中心等10栋装有据名称文字。真实徽标图形0，未给其他楼虚构停机坪。
3. 200个原足迹中115栋有某种增量几何，包含背景窗构件、主要首层及命名楼。此计数不代表115栋具名外立面或每面已精修。其余大面积背景楼仍较简化。
4. 认可的暖灰楼身、蓝灰玻璃、深绿植被、砖红/琥珀商业点缀贯穿独立街区；原配色可切换，几何及灯光不随配色变化。
5. 20棵分枝冠层树（含这轮商城可见8棵密冠），16棵中距树、树池/低篱/座椅；原总1250树位保持，其余仍有球冠。
6. 一处四臂路口的斑马线、停止线、导向、信号控制；光华路两侧骑行色带、护栏、路名导视、短圆反光柱、坡口、既有单车泊位，另加P导视/百叶箱/信号附属设备。
7. 88辆5类车在原道路上双向连续运行，具真实红灯制动与交叉口清空；52人总池内保8名固定商城行人，其中2名进入近景原有铺地。展示流量、信号时序与设施细位置为制作推断，不是交通工程实测。
8. 修正背景楼墙面绕序/法线；汉威入口落地、中国大饭店实际退门与幕墙底缝已实际图检查。千禧原随机30.46m体块改为104m外部估值形体；国贸A/B与中国尊源高度实际约329.80/295.92/528.02m，未因透视误差任意拉高。

完整200足迹逐栋清单见 CBD_BUILDING_COVERAGE.csv，逐列区分几何增量、有据文字、示意商铺、海报、停机坪与像素限制。表内原地图高度保持源记录，并不代表当前模型实测高度。

## 验证范围

- 使用真实Three几何、LOD、面方向、实例矩阵、同源逐时刻车流的CPU离屏图，对已制作的主要视图逐批观察并修错。原失败图保留在开发证据中。CPU的玻璃环境反射、程序shader和光照仍近似。
- 最终120秒完整车流：完整车身穿楼0、出路0、可见瞬移0，最小同边间距1.8016m，无连续空车流秒段。
- 最终前场8名固定人120秒无穿楼；新增2人的道路/街具碰撞0，最小固定人净距0.3659m，鞋底与铺地几何误差约1.12e-8m。接触影新增腿/鞋2个真实实例投影批次。
- 两档反复切换、583个mesh配色恢复、164个JS模块与494条相对导入检查通过。原独立数据及第一轮冻结ZIP未改。
- CPU构建约2.41秒，记录时Node RSS约445MB，几何属性/索引约65.51MB；这些不是浏览器峰值。按LOD和视锥的商城标准估算约281批/728k三角、轻量278批/620k三角，也不是GPU实际提交或帧率。

## 明确未通过或仍不足

- 没有原WebGL浏览器实画、shader编译、旋转缩放控件实操、标准/低配设备FPS验收。私有站已部署不等于浏览器验收。
- 精致度仍不及参考艺术效果：部分远树球冠、背景立面空白、局部树遮小字、远楼名称像素不足。千禧上行GRAND在整楼图很小，三星背阳字仍较暗。
- 10栋名称、单栋商城原创商业招牌/广告不是“各楼标识全补完”；更多楼栋真实商户/企业牌仍需逐栋图证和制作。
- 千禧104m为外部估值；许多窗跨、门口、罗盘挂面及设施尺寸为有边界推断，不能称逐物实测复刻。
- 原全北京至少50条可辨街景未达；这轮按最新要求集中CBD，不增加已验收全城街道数。
